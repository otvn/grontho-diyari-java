# Grontho Diyari

A console-based Java bookstore/library project demonstrating core object-oriented programming concepts.

## Features
- Student registration
- Category-wise book selection
- Book information and pricing
- Student discount calculation
- Shop and stationery information
- Total sales calculation
- Console-based menu navigation

## Concepts Used
- Classes and objects
- Inheritance
- Method overloading
- Method overriding
- Encapsulation
- Static members
- Varargs
- `Scanner` for user input
- Interface declaration

grontho-diyari-java/

## How to Run

Install a Java JDK, then run:

```bash
cd src
javac *.java
java MainClass
```

The application starts from `MainClass.java`.
